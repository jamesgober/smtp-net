# smtp-net v0.2.0 - Design Lock

**Date:** 2026-11-04
**Compare:** [`v0.1.0...v0.2.0`](https://github.com/jamesgober/smtp-net/compare/v0.1.0...v0.2.0)

**The public API, written down before the code.** v0.2.0 locked every name, signature, behaviour, and error of smtp-net from `0.3.0` to `1.0.0` in [`docs/API.md`](https://github.com/jamesgober/smtp-net/blob/main/docs/API.md), answered every open design question, and set the version roadmap. There is no functional code in this release; it was published to claim the crate name.

## What's in 0.2.0

- **`docs/API.md`.** The one-call path (`Message::text`, `Message::html`, `send`, `send_local`, `send_prepared`), addresses, the message builder and its budgets, encoding primitives, serialization sinks, envelopes and the checksummed job payload (`PreparedMessage`), the sans-IO `Session` with its events and deadlines, replies and capabilities, SASL, DKIM, the blocking `Client` and `Pool`, the `TlsConnector` seam, the `SendGate` pacing hook and `HourlyLimit`, timeouts, the `Observer` hook, errors with their temporary or permanent disposition, the test server with fault injection, and constants. Each item carries its grade (P0 to P3), tier (1 to 3), the version that ships it, and a cost target.
- **`dev/PLAN.md`.** Functional and non-functional requirements, the sans-IO state machine and its rules, the failure classification table (including `possibly_delivered` after an ambiguous end of data), RFC 5321 timeouts, the message and DKIM design, 36 threats each with a defence, an attack test, and a cost, performance targets against lettre and mail-builder, the testing plan, and decisions D-005 to D-036.
- **Decisions that shape the code.** The grammar comes from parse-net 0.9; base64 and quoted-printable stay private until encode-lib exists; DKIM signing waits for crypt-io's signing module; STARTTLS and implicit TLS run through a `TlsConnector` seam over net-io's sans-IO TLS session, so the TLS logic does not wait for tls-net; output is 7-bit by default; plaintext submission goes only to a verified loopback peer; certificate checks can be disabled only for loopback hosts or with a second explicit flag, the same in every build.
- **Roadmap.** 0.3 core (builder, session, local submission, test server), 0.4 extended (TLS, AUTH, reuse, CHUNKING, DSN, SMTPUTF8, pacing, job payloads), 0.5 feature complete (DKIM, XOAUTH2, SCRAM, pool), 0.6 optimisation, 0.7 hardening, 0.8 alpha, 0.9 beta with a pre-1.0 polish pass, 1.0 stable.

## Verification

- Local gate on Windows and WSL Ubuntu, stable and 1.85: format, clippy in three feature modes, tests, documentation with default and all features, `cargo package` in a fresh target directory.
- CI green on every platform before the tag.

## What's next

`0.3.0` ships the core: addresses, the message builder, the sans-IO session with PIPELINING, SIZE, and 8BITMIME, the blocking driver for local submission, and the test server.
