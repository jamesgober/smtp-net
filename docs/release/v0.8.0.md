# smtp-net v0.8.0 - Simpler API

**Date:** 2026-11-11
**Compare:** [`v0.7.2...v0.8.0`](https://github.com/jamesgober/smtp-net/compare/v0.7.2...v0.8.0)

**The first alpha: the same features, with the API simplified before the field test, and every finding of an independent review of 0.7.1 fixed.** A review of every public item against four rules (a one- or two-line send, plain names, one way to do each thing, a complete API reference) found eleven problems, recorded in [`dev/SIMPLICITY-AUDIT.md`](../../dev/SIMPLICITY-AUDIT.md). This release fixes all of them; most are renames or moves, and the table below maps every 0.7 name to its 0.8 replacement. The independent review's critical finding shipped as 0.7.2; its four medium, eight low, and seven note findings are fixed here, each with a test that failed first. Message bytes are unchanged except for the DKIM `h=` list and how long display names fold.

A gate written for 0.7 that counted recipients reads them from the envelope now, and refunds at the time it admitted:

```rust
use smtp_net::{Admission, Envelope, SendGate};
struct Shared(std::sync::Arc<smtp_net::HourlyLimit>);
impl SendGate for Shared {
    fn admit(&self, envelope: &Envelope, now_unix_ms: u64) -> Admission {
        self.0.admit(envelope, now_unix_ms) // was: self.0.admit(recipients, now_unix_ms)
    }
    fn refund(&self, envelope: &Envelope, admitted_unix_ms: u64) {
        self.0.refund(envelope, admitted_unix_ms)
    }
}
```

## Fixed

- **A `DomainLimit` reached through the count-based `SendGate::admit` admitted every message.** A count carries no domains, so the method had nothing to check. The client used the envelope methods and was not affected, but a caller or a combinator that used the count method got no per-domain limit, and nothing warned it. `SendGate` now has one pair of methods, and both take the envelope (D-111).
- **Writing the body ran under the wrong deadline.** The body was written under the deadline left by the last reply read (`data_init`, 2 minutes), not under `data_block` per block, so a 25 MiB message over a link moving 150 KB/s timed out on every retry. Writes now use the same deadline as reads, renewed per block (D-120).
- **`Timeouts::total` was documented and never read.** It now bounds the whole send, connect and TLS included, and for a `Pool` from before the connect; its expiry is `Timeout` at `Stage::Total` (D-120).
- **DKIM did not oversign the MIME headers, Sender, or List-Unsubscribe.** A verifier hashes the bottom-most instance of each name in `h=`, so a second Content-Type, Content-Transfer-Encoding, MIME-Version, Sender, or List-Unsubscribe added above the signed one passed verification on a replayed message. Every default header is oversigned now (D-121).
- **Long display names were not folded.** A From, To, or Cc line could pass 998 octets, and the stored job payload of such a message could not be decoded. Names fold at their spaces, or go to RFC 2047 words when a word is too long for a line, and a name over `max_header_value` is refused at build (D-122).
- **A refund was lost when the failure came in a later minute than the admission**, so a relay outage used up the hour's budget on sends that never happened (D-123).
- **The 512-octet command limit counted ESMTP parameters**, refusing a long address with DSN; ENVID's 100-character limit was measured before xtext, so it could triple on the wire; the refusal said `Usage(Closed)`. The 512 now holds the command and path, parameters have their RFC allowances, an ORCPT over 500 characters is left out, and ENVID is measured as sent (D-124).
- **An EHLO reply over 1 KiB was cut before its capabilities were read**, so a cut `SIZE` became a tiny limit and later extensions vanished. EHLO replies are kept whole up to the reply budget; `ReplyLimits::max_lines = u16::MAX` no longer overflows the line counter (D-125).
- **A quoted local part could carry parameter-shaped text onto the RCPT line** (`"x> NOTIFY=SUCCESS"@example.com`). `Address::parse` refuses a quoted local part with a space or one of `< > @ = ; ,` (D-126).
- **The address-like display-name policy missed the full-width and small at signs; file names took bidirectional overrides and zero-width characters** (`invoice\u{202E}fdp.exe` shows as `invoiceexe.pdf`). Both are refused now, file names under `allow_bidi_controls` (D-127).
- **A reply that arrived before its command was written was accepted**: a 220 read with the EHLO reply was taken as the answer to an unsent STARTTLS. It closes the session now, as `StartTlsInjection` for STARTTLS (D-128).
- `DomainLimit` could forget a counted domain when its table was full, which reset that domain's count; the output buffer could be freed unwiped when it grew for an AUTH line; `Secret` compared in variable time; `Mailbox::parse` refused a quoted `<` in a display name; decoding many recipients was quadratic; `Mailbox` displayed with a line break (D-129, D-122).
- `Server::starttls` and the other one-line constructors skipped the builder's host check; the first connect now returns `Config(InvalidHost)` before anything is sent (D-130).

## Changed

- The crate root keeps what an application uses. The sans-IO core moved to `smtp_net::protocol`, MIME parts, encoders, sinks, and randomness to `smtp_net::mime`, the canonicalizers to `smtp_net::dkim`, and test support to `smtp_net::testing`. Each item has one path (D-110).
- One method per job: `ServerBuilder::tls` takes any `TlsConnector` (D-112); `Message::prepare_signed` is gone in favour of `prepare()?.sign(..)` (D-113).
- Plain and consistent names: `PORT_STARTTLS` and `PORT_IMPLICIT_TLS` (D-115); `with_` setters on `Dsn` and `Envelope`, with getters that carry the field's name (D-116); `DomainLimit::recipients`, `ReplyCode::is_temporary`, `QuotedPrintableState` (D-117).
- The `ServerBuilder` chain never stops for a `Result`: `mechanisms` and `client_name(&str)` are checked by `build()` (D-118).
- `docs/API.md` was rewritten as a task-oriented reference of every public item. Its examples and the README's compile and run as doctests (D-110).
- net-io 0.7.2 and tls-net 0.9.1 are the minimums; net-io yanked 0.7.0 and 0.7.1 (D-132).

## Added

- `RejectedRecipient`, the one shape of a refused recipient in a `Report` and in an `Error` (D-114).
- `ClientName::parse` for a domain, an IP address, or an RFC 5321 literal; `ConfigError::InvalidClientName` (D-118).
- `Server::oauth2(user, token)` (D-130); `AddressError::RiskyQuotedLocalPart` (D-126).
- `dev/SIMPLICITY-AUDIT.md`: the findings, what was kept and why, and what the change touches.

## Costs

- Every read and write computes one deadline; no allocation.
- DKIM: about 150 octets more `h=` per signature and 15 more empty header hashes, under 1 µs (an estimate).
- Up to 8 KiB held while an EHLO reply over 1 KiB is read, given back after.
- `DomainLimit` scans its table only when it is full.

## Verification

- Every test on Linux, macOS, and Windows, stable and 1.85, and the doctests of every example in `docs/API.md` and the README. Each review finding has a regression test that fails on 0.7.1, among them `test_body_writes_are_timed_per_block_not_by_the_data_reply`, `test_total_timeout_bounds_the_whole_send`, `test_every_default_header_added_in_transit_breaks_the_signature`, `test_long_display_names_fold_and_the_payload_decodes` with a property test over display names of any length, `test_refund_gives_back_to_the_admission_time`, `test_ehlo_reply_over_1_kib_keeps_every_capability`, `test_quoted_local_parts_that_read_as_parameters_are_refused`, `test_reply_before_its_command_is_written_closes_the_session`, and `test_table_is_bounded_and_never_forgets_a_counted_domain`.
- Uncontended `HourlyLimit` admission, 0.8.0 against 0.7.1 on Linux, alternating builds under a load average of 45 to 72: 83.4 ns against 84.2 ns, then 64.4 ns against 61.6 ns, level within noise (D-111). The 30 ns figure in `docs/PERFORMANCE.md` was measured on a quiet machine, and 0.9 re-measures it the same way.
- Fuzz targets built, loom models passed, `cargo deny` and `cargo audit` clean, `cargo package` from a fresh target directory.
- Not run: a real Postfix (none on the build machine). `TestServer` now answers a nested MAIL as Postfix does, and the interop matrix of the field test includes Postfix.
