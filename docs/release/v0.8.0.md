# smtp-net v0.8.0 - Simpler API

**Date:** 2026-11-12
**Compare:** [`v0.7.2...v0.8.0`](https://github.com/jamesgober/smtp-net/compare/v0.7.2...v0.8.0)

**The first alpha.** Same features as 0.7, with the API cleaned up before the field test and a batch of bugs fixed. Most of the API changes are renames or moves; the table below maps every 0.7 name to its 0.8 one. Message bytes are the same, except for the DKIM `h=` list and how long display names fold.

A gate written for 0.7 reads the recipients from the envelope now, and refunds at the time it admitted:

```rust
use smtp_net::{Admission, Envelope, SendGate};
struct Shared(std::sync::Arc<smtp_net::HourlyLimit>);
impl SendGate for Shared {
    fn admit(&self, envelope: &Envelope, now_unix_ms: u64) -> Admission {
        self.0.admit(envelope, now_unix_ms) // was: self.0.admit(recipients, now_unix_ms)
    }
    fn refund(&self, envelope: &Envelope, admitted_unix_ms: u64) {
        self.0.refund(envelope, admitted_unix_ms)
    }
}
```

## Fixed

- `DomainLimit` let everything through when reached through the old count-based `SendGate::admit`. A count has no domains to check. `SendGate` now has one pair of methods, and both take the envelope.
- The body was written under the deadline left by the last reply, not under `data_block`. A big message on a slow link timed out on every retry. Each block now gets its own deadline.
- `Timeouts::total` was documented but never applied. It now bounds the whole send, connect included, and fails with `Timeout` at `Stage::Total`.
- DKIM didn't oversign MIME-Version, Content-Type, Content-Transfer-Encoding, Sender, or List-Unsubscribe, so someone replaying a message could add one of them and the signature still passed. Every default header is oversigned now.
- Long display names weren't folded. A From, To, or Cc line could pass 998 octets, and the saved job payload then wouldn't decode. Names fold at spaces now, and a name too long for the header budget is refused.
- A gate refund was lost when the failure came a minute or more after the admission.
- The 512-octet command limit counted the ESMTP parameters, so a long address with DSN was refused. ENVID's 100-character limit was checked before encoding. Both now follow the RFCs, and an ORCPT over 500 characters is left out.
- An EHLO reply over 1 KiB was cut short before the capabilities were read, so a cut `SIZE` became a tiny limit. EHLO replies are kept whole now.
- A quoted local part like `"x> NOTIFY=SUCCESS"@example.com` went onto the RCPT line as it was. `Address::parse` now refuses a quoted local part with a space or one of `< > @ = ; ,`.
- The address-like display-name check missed the full-width and small at signs. Attachment file names took bidirectional overrides and zero-width characters (`invoice\u{202E}fdp.exe` shows as `invoiceexe.pdf`). Both are refused now; file names follow `allow_bidi_controls`.
- A reply that came in before its command was sent was accepted. It now closes the session.
- Smaller ones: `DomainLimit` could forget a domain that still had counts; the output buffer could be freed without being wiped when it grew for an AUTH line; `Secret` compared in variable time; `Mailbox::parse` refused a quoted `<` in a display name; decoding a payload with many recipients was slow; `Mailbox` printed with a line break in it; `ReplyLimits::max_lines = u16::MAX` overflowed a counter; `Server::starttls` and the other one-line constructors didn't check the host.

## Changed

- The crate root keeps what an application uses. The sans-IO core moved to `smtp_net::protocol`, MIME parts, encoders, sinks, and randomness to `smtp_net::mime`, the canonicalizers to `smtp_net::dkim`, and test support to `smtp_net::testing`. Each item has one path.
- One way to do each thing: `ServerBuilder::tls` takes any `TlsConnector`, and `Message::prepare_signed` is gone in favour of `prepare()?.sign(..)`.
- Plainer names: `PORT_STARTTLS` and `PORT_IMPLICIT_TLS`; `with_` setters on `Dsn` and `Envelope`; `DomainLimit::recipients`, `ReplyCode::is_temporary`, `QuotedPrintableState`.
- The `ServerBuilder` chain never stops for a `Result`: `mechanisms` and `client_name(&str)` are checked by `build()`.
- `docs/API.md` covers every public item, and its examples and the README's run as doctests.
- net-io 0.7.2 and tls-net 0.9.1.

## Added

- `RejectedRecipient`, the one shape of a refused recipient in a `Report` and in an `Error`.
- `ClientName::parse` and `ConfigError::InvalidClientName`.
- `Server::oauth2(user, token)` for Gmail and Microsoft 365.
- `AddressError::RiskyQuotedLocalPart`.

## Costs

- DKIM signatures carry about 150 more octets of `h=`.
- Up to 8 KiB is held while a long EHLO reply is read.
- Everything else is a comparison or a deadline per read or write.

## Verification

- Every test on Linux, macOS, and Windows, stable and 1.85, plus the doctests. Each bug fixed here has a test that fails on 0.7.1.
- `HourlyLimit` admission is level with 0.7.1 within noise on a loaded machine; 0.9 re-measures it on a quiet one.
- Fuzz targets build, loom passes, `cargo deny` and `cargo audit` are clean.
